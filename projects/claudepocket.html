手机只负责显示和按键，真正在干活的是电脑上那个 Node agent —— 它管 tmux，tmux 里跑着 claude。

能力

它替你解决的那些小事

每一条都是仓库里已有的行为，不是设想。

会话不跟着手机走

Claude 在电脑上继续跑。你在电梯里、地铁上、锁屏一小时后回来，输出还在，历史还在。

扫码配对，两道门

先在 Mac 上过一次系统验证（Touch ID，没有指纹就退回登录密码），手机扫完电脑上还会再问一句。

那张票 32 字节随机、五分钟、一次、只活在 agent 内存里。

每台设备一把自己的钥匙

配对后电脑当场生成只属于这台手机的 deviceKey；电脑上只存它的 sha256，读到文件也给不出凭据。

名册里能看谁什么时候配的、最后什么时候用过，随时可以吊销。

手机也能翻电脑上的文件

从 home 开始的只读浏览：代码带高亮和行号，图片能放大，二进制如实说打不开。

文本每次最多 512 KB、图片 4 MB —— 有上限，所以那条 socket 不会被一个文件堵住。

接着以前的会话

列的是 Claude Code 自己的 resume 列表，不是一个另存的副本。

会话正被别的进程占着时，app 会先警告 —— 两处同时 resume 会让历史分叉。

是真的终端

WebView 里跑 xterm.js，接的是真 pty —— 所以换行、光标、宽字符、颜色都对。

字体按终端的实测度量，Unicode 11 宽度、拖拽滚动都调过。

这一台可以按

右上角那列灯，一个开着的会话一盏：正在吐输出的运行中会呼吸，安静 5 秒变空闲，安静超过 30 秒变等待输入。点一盏就切过去。

下面那排键也是真的 —— 它们补的正是软键盘造不出来的那几个键，按一下就往那个会话里发一次。状态牌说的是连接，灯说的是会话，是两件事。

点一盏灯，或者按一下 Ctrl+C 试试。

顶栏：两个入口

左边是当前会话名，右边一块状态牌：已连接 / 连接中 / 离线 / 出错 / 凭据失效。

再往右两个按钮就是全部入口 —— ↺ 恢复会话 和 + 新建会话。它们就挨着会话名，因为要打开的正是这个项目的对话，不该先划一下抽屉才够得着。

灯柱：一眼看全部会话

终端右上角竖着一列小灯，一个开着的会话一盏，按开着的顺序排。正在吐输出的那盏会呼吸（运行中）；5 秒内没输出算空闲，超过 30 秒算等待输入 —— 灯黄了不是它要你回答，只是它没在说话。

灯多了会自己变小（12 → 8 px），长到终端一半高就不再缩 —— 那时候该用抽屉了。点灯直接切会话。

快捷键条

只有开着会话时才出现，补的是手机软键盘造不出来的键：

EscTabCtrl+CCtrl+DCtrl+L
←↑↓→Enter

打字不用它 —— 直接用手机自己的输入法打在终端里。上面那个模型里这排键是真能按的。

抽屉（左滑）

会话列表（一行一个，点一下切过去）、字号 10–20、行高 0.9–1.6、保持屏幕常亮、浏览文件、新建会话。

字号和行高是给不同手机准备的：同样的 100 列，在小屏上要能读得下去。

✕ 是「结束」，不是「收起」

会话列表里那个 ✕ 会给电脑发一条 DESTROY：那个 tmux pane 和里面跑着的 claude 真的结束了。

只是想放下手机？不用点它 —— 按 home 键、锁屏、切出去，电脑那边什么都不做。

没有会话列表要管理，也没有一堆设置等着你 —— 打开就该看见终端。

第一次连上，两个入口

扫码配对（推荐）

电脑上点「配对」→ 手机扫 → 电脑上确认一次。之后这台手机有自己的钥匙，不用再记 token。

详细的两道门见下面「配对」一节。

地址（IP）、端口、旧 token、项目路径（电脑端，可以点「浏览」挑目录），或者把电脑上打印的 claudepocket:// 链接粘贴进来。

配对过的手机不用填 token —— 对话框里那行提示写的就是这句：它带的是自己的钥匙。

每天怎么用

  1. 新建一个会话

    顶栏 + → 选项目路径 → 电脑上就开出一个 tmux pane，里面跑起 claude。手机上看到的是它的屏幕。

  2. 接着以前的会话

    顶栏 ↺ 列的是 Claude Code 自己的 resume 列表（当前项目 / 所有项目），不是一个另存的副本。

    正在运行此会话。在此恢复会导致两处同时写入。
    —— 那个会话正被别的进程占着时，app 会先问这句

  3. 随手丢开

    锁屏、切出去、进电梯断网 —— 电脑那边什么都不做。断开不等于结束：tmux 会话留着，下次连上重新接管，并把断开期间攒下的输出从头补给你，一条不丢。

  4. 不想它熄屏

    抽屉里的保持屏幕常亮管这件事。手机多少秒没触摸会熄屏、熄屏之后 Wi-Fi 断不断，都是手机自己的设置 —— 断了就是连接掉一次，会话没事。

  5. 顺手翻一下电脑上的文件

    抽屉 → 浏览文件，从 home 开始，只读。看到代码带高亮和行号，图片能放大，二进制文件它会如实说打不开。

配对

码是票，不是钥匙

两道门，中间夹着一张只兑一次的票。

电脑上 · 菜单栏面板未配对

先过一次系统验证 —— 过了才出码。

手机上未配对

还没连过这台电脑。

  1. 电脑上点「配对」，先过系统验证

    Touch ID，没有指纹的机器退回登录密码。这一步完全是本机的事：密码从头到尾都在系统手里，这个应用既不读也不存。按「取消」，面板上就写「没有通过系统验证，没有生成配对码」—— 没有码。

  2. 过了验证，才出一张二维码

    32 字节随机数，五分钟、一次、只活在 agent 内存里。五分钟一到，面板上那个码自己消失，位置上换成「已失效 · 重新生成」。

    拿到它就能配一台设备 —— 所以它只该出现在你自己看着的屏幕上。

  3. 手机扫完，电脑上再问一句

    那句话写的是这台电脑自己看到的地址，以及手机自称的名字 —— 地址是事实，名字是对方说的。这句问话会自己弹到最前面，不需要面板开着，只等两分钟。

  4. 手机拿到只属于它自己的钥匙

    agent 当场生成 deviceKey，手机存下来，以后每次连接都带着它。电脑上写的只是它的 sha256。

安全模型

这台机器上的东西，凭什么给手机

默认值是「同一个 Wi-Fi 下谁拿到凭据谁就有读权限」—— 终端本来就能读任何东西，所以这不是新增的暴露，但值得知道。

票不是钥匙

配对码是五分钟、一次的票，兑不了第二次。同一个码再扫一遍，手机只会听到「这个配对码已失效」。

凭证是设备级的

吊销某台设备，它下一次连接会被当面告知（不是连不上，是连上了再被请出去），而且不会自动重连回来。重新扫一张新票就能再配上。

控制口不出本机

应用面板从 127.0.0.1 上的控制口要票、读名册、吊销设备。它只绑回环地址，并且拒绝任何带 Origin 的请求 —— 一个浏览器标签页没法调到它。

日志里没有秘密

启动日志只打 token 的前后各四位指纹，够你分辨是不是同一个 token，不够当 token 用。链接也不进日志。

边界

它不做什么

把话说在前面，省得你以为它能干。

网络

它不会打洞，也不做中转。 agent 就是一个监听在本机网卡上的服务：不在同一个网段时，你得自己准备一条能路由到这台 Mac 的路（VPN 之类）。反过来说，手机存的是一个具体地址 —— 换了网络环境要换对地址。

手机

屏幕是手机的屏幕。 手机多久熄屏、熄屏之后 Wi-Fi 断不断，是手机自己的设置决定的；断了意味着连接会掉一次，会话本身没事。

历史

两处同时 resume 同一个会话，历史会分叉。 Claude Code 的 resume 只沿着一条 parentUuid 分支走，另一条在磁盘上还在，但不会再被显示。所以 app 在恢复一个正被占用的会话时会先警告。

平台

Mac 端目前是 macOS。 电脑那头是个菜单栏应用，手机这头是个 Flutter 应用（Android 已经在打 APK）。电脑上需要 tmux —— 会话活在里面。

常见问题

别人最常问的几句

我关掉手机，Claude 会停下来吗？

不会。会话活在一个 tmux pane 里，手机只是一块屏幕。关 app、断网、熄屏，pane 都还在原处，重连回去接着看。

真正会结束会话的是：在电脑上退出或停止这个 app（agent 收到 SIGTERM 就把 tmux 会话清了，和你在终端里按 Ctrl-C 一样）—— 所以有会话在跑时它会先问一句。

旧 token 和新钥匙是什么关系？

token 是这台机器的第一份凭据：一串 32 字节的随机值，只落在电脑上一个权限 0600 的文件里。老手机、老流程照常工作，它在名册里以「旧 token（本机文件）」出现。

新配对出来的是一把设备级的 deviceKey，电脑上只写它的 sha256。设备可以单独吊销 —— 而吊销旧 token 会删掉那个文件，并留下一块墓碑，重启 agent 也还是吊销状态。

Mac 提示「Apple 无法验证 ClaudePocket」怎么办？

这个包是 ad-hoc 签名、还没有做 Apple 公证，所以从网上下载后会触发 Gatekeeper 拦截。把它拖进「应用程序」，然后任选一种：

① 双击一次、在弹窗里点取消 → 打开 系统设置 → 隐私与安全性，在「安全性」一栏点「仍要打开」→ 用 Touch ID / 密码验证 → 再确认一次。

② 打开终端，跑 xattr -dr com.apple.quarantine /Applications/ClaudePocket.app，然后再双击。

macOS 15 起右键 → 打开不再能绕过这个拦截，必须走上面的「仍要打开」。另外 app 必须先复制到 /Applications，直接在只读的 dmg 里点也会失败。

不用装 Node 吗？

不用。Mac 那个应用里自带运行时和全部逻辑，装上就是一个普通应用。只有你自己从项目里打这个包时才需要 Node ≥ 18。

手机上的二维码能截图发群里吗？

不要。链接里带的是一张票：五分钟、一次 —— 但拿到它就能配一台设备。所以那个码只该出现在你自己看着的屏幕上，也不要贴进聊天记录。

顺带一提，启动日志里一个 token 也不打，链接也不进日志。

它和「把终端投屏到手机」有什么不一样？

投屏传的是像素，它传的是会话。所以手机这边可以做真正该在手机上做的事：窗口大小自己调、按键走软键盘工具条、文件能翻、会话能挑着 resume。

而且电脑那边不需要开着一个共享屏幕的窗口等你看 —— agent 是个后台服务，手机连不连，它都在那儿。
