全景

两端，一件事

会员在手机上提交和查看，会长和秘书在后台审批和管理 —— 两边看的是同一套数据。

会员手机端

提交入会 · 看商会地图 · 记备忘录

⇄同一套数据与权限

会长 / 秘书后台

审批入会 · 管成员与企业 · 发公告

01

商会是一棵树

每个商会都有上级商会；省/市/区、会长、秘书长、各级年费各自独立。

02

数据按商会隔离

会长和秘书只看得见自己商会的人；换成别的商会，系统根本不会把数据端出来。

03

入会必须走审批

申请要人批；批准的那一刻才授予角色、才建立企业关联。

能力

它替你解决的那些小事

每一条都是系统里现在就能用的。

商会地图

高德底图，商会 / 企业 / 会员三类标记。默认显示附近的公司（游客 20 公里、会员 50 公里），也能只看我加入的商会，还能按行业筛。

入会申请与审批

申请人在 app 里填表提交，会长或秘书在后台批；批准时顺手授予角色。

成员与企业档案

会员档案记身份、企业、职务、联系方式；企业档案记信用代码、营业执照、经营范围、行业。

行业分类

两级行业树，可增、可删、可启停；地图筛选和成员档案共用同一套分类。

公告与备忘录

商会公告发布后进 app；备忘录挂在人 / 企业 / 商会下面。

角色权限

按商会授权的角色体系；除了五个固定角色，还能自建角色、逐项勾权限。

后台

后台长这样

左边是全部菜单，点一下看它的列表页 —— 列名和筛选项都取自真实页面。

地图不止是地图

搜索卡分「全部 / 商会 / 公司」三段；右上角三个钮管「名称 / 选点 / 定位」；点标记弹出商会或公司的详情卡。

申请和记录在同一屏

「提交申请」和「我的记录」是页内两个 Tab。申请单先存草稿，再提交；退回和驳回都会写明原因。

备忘录挂在关系上

一条备忘录同时关联商会、公司和时间，所以在地图弹窗里也能直接看到最新两条。

一个账号，多个商会

「我的」里列出你加入的每个商会，点一下切换当前商会，管理入口只对有权限的人出现。

第一次用，三步

  1. 登录

    手机号验证码即登录，新号码自动注册成游客；也能用密码加图形验证码登录。

  2. 看地图

    不登录就能看地图和商会详情；登录后可搜索、可按类别筛选。

  3. 提交入会

    选商会、填企业信息，可以先存草稿；提交后等会长或秘书在后台批。

角色与权限

谁看得见谁的数据

五个角色，两级管辖。不是自己商会的人和事，系统根本不会端出来。

角色管辖范围能做什么
超级管理员全部商会管商会、管行业、配权限，以及所有商会的审批
会长本商会管成员、审批入会、发公告
秘书本商会管成员、日常审批、发公告
正式会员本商会查看本商会成员、使用地图
游客—浏览地图、提交入会申请

一张申请单要走的路

草稿 提交 ──▶ 待审批 批准 ──▶ 已通过
待审批 退回 ──▶ 已退回 重新提交 ──▶ 待审批
待审批 驳回 ──▶ 已驳回 撤回 ──▶ 已撤回 重新提交 ──▶ 待审批

批准的那一刻做两件事：授予角色、建立企业关联。 退回和驳回都要填原因，申请人看得见。

后台里勾的就是这些

一个角色能勾的项就是下面这些。勾上就看得见、点得动；没勾的，整个入口都不出现。

商会：查看 · 新建 · 编辑 · 删除
成员：查看本商会 · 查看全部 · 编辑资料 · 指派角色 · 移除成员
入会审批：查看全部 · 查看本商会 · 审批入会
行业 / 角色 / 公告：行业维护 · 角色配置 · 公告发布
企业档案：查看 · 新增 · 编辑 · 删除
备忘录：查看 · 新增 · 编辑 · 删除

手机端

会员用的那一端：看商会地图、提交入会申请、记备忘录。微信小程序、H5、安卓都有。

先看看手机端

打开之后，三步

  1. 打开后台

    点上面的地址，浏览器直接就进。不用注册，不用等审核。

  2. 登录

    手机号加验证码就能进；也可以走账号密码加图形验证码。

  3. 提交一份入会申请

    选商会、填企业信息、提交，再去审批页把它批掉 —— 一条完整链路就走完了。

边界

它不做什么

下面这些是真的做不到，不是「暂未支持」。

地图

地图用的是高德底图，要单独开通接入；没开通就只有列表，没有地图。

审批

入会是单级审批（会长 / 秘书 / 超管任一即可），不是多级会签流程。

权限

隔离粒度是商会级，不是字段级；同一商会内的成员默认可互看档案。

登录

手机号验证码登录要接短信通道；没接短信时走账号密码 + 图形验证码。

备忘录

备忘录是挂给人 / 企业 / 商会的记录，不是多人协同文档。

多商会

一个账号可属于多个商会，但 app 同一时刻只在一个商会里活动。

常见问题

别人最常问的几句

一定要装 app 吗？

不。游客不登录也能看地图和商会详情；只有提交入会申请需要登录。

地图上的公司从哪来？

来自企业档案。地图默认显示附近的公司 —— 游客 20 公里、会员 50 公里；也能只看我加入的商会。

批准入会之后发生了什么？

授予角色 + 关联企业，申请人从游客变成会员。

看不见别的商会的数据？

按商会隔离。不是自己商会的成员和企业，系统根本不会端出来，不是界面上藏起来。

能自己加角色吗？

能。后台「角色权限」里新增角色，然后勾权限树。

一个手机号能进多个商会吗？

能。登录后在个人中心切换当前商会。
